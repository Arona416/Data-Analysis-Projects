# Bike Sales Analysis – Excel Dashboard

## Project Overview

This project focuses on analyzing bike purchasing behavior using Microsoft Excel. The objective is to explore customer demographics, income levels, education, commuting distance, and purchasing patterns to identify useful business insights.

An interactive Excel dashboard was developed using Pivot Tables, Pivot Charts, and Slicers to make the analysis easier to explore.

## Business Objectives

- Analyze bike purchasing behavior across different customer segments.
- Compare average income between customers who purchased bikes and those who did not.
- Explore purchasing patterns by gender, age group, and marital status.
- Understand how commuting distance relates to bike purchases.
- Build an interactive dashboard for business decision-making.

## Dataset Description

The dataset contains customer information and purchasing behavior.

| Column | Description |
|---|---|
| ID | Customer identification |
| Marital Status | Customer marital status |
| Gender | Customer gender |
| Income | Customer income |
| Children | Number of children |
| Education | Education level |
| Occupation | Professional occupation |
| Home Owner | Home ownership status |
| Cars | Number of cars |
| Commute Distance | Distance travelled to work |
| Region | Customer geographical region |
| Age | Customer age |
| Purchased Bike | Whether the customer purchased a bike |

## Dashboard Features

The dashboard provides several interactive visualizations:

1. **Average Income Purchase Analysis:** Compares average income by gender and bike purchasing status.
2. **Customer Age Bracket:** Examines purchasing behavior across different age groups.
3. **Commute Distance Analysis:** Compares bike purchases across commuting distance categories.
4. **Customer Age Analysis:** Visualizes purchasing patterns by customer age.
5. **Interactive Filters:** Allows users to filter results by marital status, region, and education.
