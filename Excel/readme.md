# Sales Performance Analysis with Excel

## Project Overview

This project focuses on analyzing sales performance using Microsoft Excel.

The objective is to explore sales data, identify business trends, compare revenue across countries, and analyze annual performance through Pivot Tables and data visualization.

## Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Data Cleaning
* Data Aggregation
* Data Visualization
* Exploratory Data Analysis (EDA)

## Project Objectives

* Analyze revenue by country.
* Evaluate yearly sales performance.
* Explore product and customer-related metrics.
* Calculate and compare financial indicators.
* Extract meaningful business insights.

## Key Analysis

### 1. Revenue by Country

Comparison of sales revenue across different countries.

### 2. Annual Revenue Analysis

Evaluation of revenue trends from 2011 to 2016.

### 3. Financial Performance

Analysis of Revenue, Cost, and Profit.
